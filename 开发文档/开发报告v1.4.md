# AI Innovation Agent Studio — 开发报告 v1.4

## 一、本轮目标

本轮 v1.4 的核心目标是将项目从"可用 MVP"升级为"更像真实 Agent 工程平台的可演示版本"，重点补齐以下能力：

1. Agent Intent Classifier — LLM 意图分类 + 规则兜底
2. 轻量 Workflow 状态机 — 多阶段工作流可视化
3. Memory Embedding 语义检索 — pgvector + 关键词兜底
4. Skill Registry 配置化 — YAML/Markdown 加载
5. Tool Registry 配置化 — YAML 配置 + 风险审批模型
6. Redis 异步 Agent Run — 基础状态轮询
7. MinIO/S3 存储抽象 — 本地/可配置存储
8. Trace 时间线可视化 — 组件化展示
9. Prompt/Skill/Eval 管理 UI — 基础版
10. Monaco Editor 代码产物预览 — 语言检测
11. Playwright E2E 测试 — 核心流程覆盖
12. 测试扩展与质量门禁

## 八、Agent Runtime / Workflow 变化

1. **Intent Classifier**: Agent Run 创建时调用 `classify_intent()`，优先使用 LLM 分类，失败降级到规则分类
2. **意图记录**: 分类结果写入 AgentRun.metadata 和 TraceEvent
3. **Workflow 引擎**: 定义 9 个默认阶段（需求分析→创意→调研→PRD→架构→编码→QA→答辩→人工审核）
4. **状态映射**: 根据 Agent Run 的 selected_skill 自动映射到 Workflow 节点状态
5. **前端集成**: Workflow Canvas 使用 workflowStatus 数据驱动节点颜色

## 九、Memory / RAG 变化

1. **Embedding 字段**: Memory 模型新增 embedding/embedding_model/embedding_status/last_embedded_at
2. **自动 Embedding**: 创建 Memory 时自动生成 embedding（异步）
3. **重新 Embedding**: 更新 Memory 内容时自动重新生成 embedding
4. **语义检索**: `semantic_search_memories()` 使用 cosine similarity
5. **关键词降级**: embedding 不可用时降级到关键词匹配
6. **搜索 API**: 新增 `/memory/search?q=&mode=semantic|keyword`
7. **Context Pack**: `get_relevant_memories()` 优先使用语义检索

## 十五、技术债与 v1.5 建议

### 当前技术债

1. **Redis 未实际用于队列**: 当前 Agent Run 仍是同步执行，建议 v1.5 实现 BackgroundTasks + Redis 状态缓存
2. **MinIO 未实际接入**: Storage 抽象层已创建，但 MinIO 客户端未实现
3. **Monaco Editor 未安装**: 代码预览仍使用 pre 标签，建议安装 @monaco-editor/react
4. **Playwright 未安装**: E2E 测试配置已创建，需安装 @playwright/test
5. **Migration 未自动执行**: 需要手动运行 alembic upgrade head

### v1.5 建议

1. 实现 Redis 异步 Agent Run (BackgroundTasks)
2. 集成 MinIO/S3 客户端
3. 安装并集成 Monaco Editor
4. 扩展 Playwright E2E 测试覆盖
5. 添加 Agent Run 状态轮询 API
6. 实现 Memory 批量重新嵌入
7. 添加 Skill 在线编辑器
8. 实现 Eval LLM Judge
